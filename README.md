# Shinobi — Sekiro mechanics for Minecraft (Fabric 1.20.1)

Сборка: `./gradlew build` (JDK 17) → `build/libs/shinobi-1.0.0.jar` → в папку mods вместе с Fabric API.
Старт в игре: `/shinobi kit`. Клавиши: Left Alt — уклонение, R — боевой приём, V — сменить приём.

Механики: осанка и её слом, добивание (в т.ч. скрытное), идеальное отражение (блок ПКМ катаной в последний миг),
опасные атаки 危 (выпад — Микири, подсечка — прыжок, захват — уклонение), уклонение с i-frames,
воскрешение, целебная тыква и семена, чётки/ожерелья, память боссов (сила атаки),
7 боевых приёмов (свитки), 12 инструментов протеза с улучшением до ур.3 у Идола Скульптора,
3 катаны, 4 босса (колокола), HUD осанки.
